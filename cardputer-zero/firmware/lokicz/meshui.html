NODE TYPE

  
The Meshtastic device role. CLIENT hears and talks; ROUTER / REPEATER nodes repeat for others and sleep less; CLIENT_MUTE listens without repeating or announcing. MeshCore on this box is the openHop repeater build — its kind is chosen by the daemon, not a setting.

  

    
    
  


  
MESHTASTIC CONFIG — ALL OPTIONS

  
Every section of the node's local + module config, read live from meshtasticd. Scalar fields are editable; nested/repeated fields are shown read-only. Saving a section writes it and reboots the node (~30 s).

MESHCORE CONFIG — OPENHOP REPEATER

  
The repeater's config file, editable here. Secrets are masked and never sent back. Saving keeps a backup (config.yaml.lokicz-bak) and restarts the repeater if it's running. The sx1262 block is the cap's wiring — change it only if the hardware changes.
